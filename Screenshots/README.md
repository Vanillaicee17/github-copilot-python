# Screenshots checklist

Everything in this folder has to come from an actual GitHub Copilot session
in your editor — none of it can be generated after the fact. Save each one
here as you complete the corresponding phase, not retroactively.

## Required

- [ ] `initial_tests.png` — terminal output of `pytest -v` passing, right
      after the test framework was first set up (before any refactor).
- [ ] `copilot_test_setup.png` (or similar) — the Copilot prompt + response
      that set up the pytest framework.
- [ ] `copilot_unique_solution.png` (or similar) — the Copilot prompt +
      response for the solution-uniqueness counter (`sudoku/solver.py`).
- [ ] `copilot_grid_styling.png` (or similar) — the Copilot prompt +
      response for the alternating 3x3 box colors / responsive / dark-mode
      CSS pass.
- [ ] `copilot_leaderboard.png` (or similar) — the Copilot prompt +
      response for the top-10 localStorage leaderboard logic.

## Also required

- [ ] At least one screenshot (or code comment) showing you rejecting or
      adjusting a Copilot suggestion, with a short note on why.

Filenames just need to be descriptive — exact names above are suggestions,
not requirements.
